# Toy demonstration results

These figures are simulated and are not biological results.

The toy dataset contains six animals: three Active and three Passive. It was deliberately
constructed so tdTom+ cells are enriched in L5 and GABA classes. Active tdTom+ cells were
given larger Oprm1, Fos, Arc, and Nr4a1 effects. The figures demonstrate the expected pipeline
outputs and interpretation.

Real pilot figures remain under outputs/orbm_right and outputs/bmap_left. The current 247-gene
pilot does not contain tdTomato.
