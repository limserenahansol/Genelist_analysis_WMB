# New Explorer exports, 2026-09-29

Nine ROIs from the six Xenium folders were run with `run_from_explorer.py --config rois_new_exports.json`.
Raw folders under `D:\output-XETG00...` were not modified.

Two sections have a full Xenium matrix and no ROI drawing: `0063814 Region_1` and `0063817 Region_3`.

`0063817 Region_1\coordinates.csv` is a byte-for-byte copy of `0063817 Region_2\coordinates.csv`. It was not used as a Region 1 drawing. Region 1 BLA polygons came from `BLA_left_right.csv`.

## How cells were chosen

| ROI | Source | Cells | Explorer complete-inside count |
|-----|--------|------:|-------------------------------:|
| orbm_r3_left | `orbm_left_cells_stats.csv` | 1019 | 1019 |
| bmap_r1_right | `bmap_right_cells_stats.csv` | 1071 | 1071 |
| orbm_r2_right | centroid inside `orbm_right_coordinates.csv` | 975 | 951 |
| bla_r1_left / right | centroid inside `BLA_left_right.csv` | 1079 / 954 | not in a cells_stats file |
| bla_r2_left / right | centroid inside Region 2 `coordinates.csv` | 751 / 1645 | 707 / 1601 |
| cea_r2_left / right | same Region 2 file | 1055 / 886 | 1013 / 852 |

Explorer counts a cell only when the whole cell is inside the polygon. The centroid rule includes some edge cells, so those counts are higher. Region 2 `orbm_right` and the BLA/CEA drawings had coordinates and combined stats, not a Cell ID list.

BLA and CEA were scored with the BMAp module gene list. That list is an amygdala-side baseline, not a CEA-specific taxonomy. CEA agreement with those modules is weaker (NMI 0.26–0.32) than BLA (0.43–0.50).

Figures for each ROI are in `outputs/<roi_name>/figures/`.
